# Contributing to Baha Ba?

First off, thank you for considering contributing to **Baha Ba?**! Community contributions help keep this platform functional and reliable for everyone.

Please review the guidelines below before submitting a pull request.

---

## 🤖 AI-Generated Code Policy

If your contribution includes code generated or significantly assisted by Artificial Intelligence tools (e.g., ChatGPT, Claude, GitHub Copilot, Cursor, etc.):

1. **Mandatory Declaration:** You **must** state in your Pull Request description that AI tools were used to generate or assist with the code.
2. **Verification & Testing:** You are fully responsible for testing and understanding all submitted AI code. Do not submit unverified AI output.
3. **Quality & Standards:** AI-assisted submissions must follow the same coding standards, architectural patterns, and readability requirements as human-written code.

---

## 🔀 How to Contribute

1. **Fork the Repository**
   Create your own fork of the project on GitHub.

2. **Create a Feature Branch**
   ```bash
   git checkout -b feature/your-feature-name
   ```

3. **Make Your Changes**
   * Keep commits focused and maintain clean commit messages.
   * Write tests where applicable.

4. **Open a Pull Request**
   * Push your branch to your fork.
   * Open a Pull Request targeting the `main` branch of the original repository.
   * Include a clear description of the changes and declare any AI assistance used.

---

## 🛡️ Governance & Merges

* Anyone is welcome to fork, adapt, and submit improvements.
* The repository maintainer retains full ownership of the original repository and sole authority over reviewing, approving, or rejecting Pull Requests for upstream merging.
